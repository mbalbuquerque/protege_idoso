# 🛡️ Protege Idoso

Plataforma web desenvolvida com foco em **proteção, assistência e acesso facilitado a recursos digitais para pessoas idosas**.

O projeto busca aplicar tecnologia a um problema de impacto social, utilizando uma aplicação web com recursos de **Progressive Web App (PWA)**, JavaScript, Node.js e serviços serverless.

---

## 🎯 Sobre o projeto

O **Protege Idoso** nasceu com a proposta de utilizar tecnologia para apoiar a proteção e assistência à população idosa.

Além do propósito social, o projeto também explora conceitos modernos de desenvolvimento web, como:

* Progressive Web Apps (PWA)
* Service Workers
* JavaScript
* Node.js
* Funções Serverless
